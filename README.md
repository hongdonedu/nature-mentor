# 🌿 네이처 멘토 2.0 — 자연이 선생님! 생체모방 발명 교실

3학년 창의적 체험활동(디지털) 6차시 프로그램용 웹앱. 왼쪽 수업 순서(0 사전검사 → 1 만나기 → 2 비밀 찾기 → 3 연결하기 → 4 발명하기 → 5 지킴이 → 6 박람회 → 7 사후검사)를 따라가며, 모든 활동 기록이 **구글 스프레드시트**에 쌓입니다. AI 네이처 멘토(Gemini)는 답 대신 **질문**을 주고, 설명문으로 **발명품 그림**을 그려 줍니다.

## 구성
| 파일 | 역할 |
|---|---|
| `index.html`, `app.css`, `app.js` | 학생용 화면(GitHub Pages) |
| `config.js` | **API_URL**(Apps Script 웹 앱 주소), 반·번호 범위 |
| `backend/Code.gs` | Apps Script 백엔드(JSON API + 시트 저장 + Gemini) |

## 설치 (15분)
### 1) 백엔드 — Apps Script
1. https://script.new → `Code.gs`에 `backend/Code.gs` 전체 붙여넣기 → 저장
2. ⚙ 프로젝트 설정 → **스크립트 속성** 추가
   - `GEMINI_API_KEY` = aistudio.google.com 발급 키 (없으면 규칙 기반 멘토로 동작, 그림 생성만 꺼짐)
   - `TEACHER_PIN` = 선생님 메뉴 비밀번호 (직접 정한 숫자; 미설정 시 setup이 6자리 난수 생성 → 스크립트 속성에서 확인)
3. 함수 `setup` 선택 → ▶ 실행 → 권한 허용 → 로그에 **데이터 스프레드시트 URL**
4. 배포 → 새 배포 → 유형 **웹 앱** → 실행 계정 **나**, 액세스 **모든 사용자** → 배포 → **웹 앱 URL(…/exec)** 복사
5. 코드를 고치면 반드시 *배포 관리 → 새 버전* 으로 다시 배포

### 2) 프런트엔드 — GitHub Pages
1. `config.js`의 `API_URL: ''` 에 복사한 웹 앱 URL 넣기
2. 저장소 Settings → Pages → Branch `main` / `(root)` → Save
3. `https://<계정>.github.io/nature-mentor/` 로 접속 → 선생님 메뉴(🔑)에서 QR 확인

## 데이터(스프레드시트 `네이처멘토_데이터`)
학생 · 설문(사전/사후 27문항+열린 3문항) · 퀴즈 · 로그(AI 대화 전부) · 비밀 · 연결 · 발명 · 반응 · 지킴이 · 소감 · 생물카드 · 설정
선생님 메뉴 → **SPSS용 시트 내보내기** → `SPSS_사전`, `SPSS_사후`, `로그요약` 생성

## 안전
- 이름 대신 반·번호만 입력, 입력 글자 수 제한, 위험어 차단, Gemini 안전 필터 BLOCK_LOW_AND_ABOVE
- API 키는 서버(스크립트 속성)에만 있고 학생 화면에는 없음(교사 매개형)
- 멘토 질문 6회/그림 3회 상한, 선생님 메뉴에서 멘토·그림 끄기 가능
